# 课程与画面规范

## 教学主线与覆盖

可按“具体问题 → 展示结果 → 拆解概念 → 观察变化 → 常见错误 → 迁移练习”组织课程，根据主题调整，不要求每段重复所有步骤。

覆盖表字段：来源章节或概念、本片段落、完整讲解/浓缩/略去、略去理由、可检查的学习结果。一本书浓缩成短课必须明确舍取，不能声称所有内容均被完整讲授。

用自己的组织与表述讲知识；引用、图片、代码与素材的必要来源和许可证保存在资料说明，不堆叠扫描页或整本朗读。受众默认有基础、刚进入该主题，用户指定其他受众时调整。先解释术语解决什么问题，再给名称。时长不足补反例、因果、排错和练习，不重复结论。

## 分镜结构

Markdown 初稿可转成结构化数据。每段稳定 ID，推荐包含：

```json
{
  "id": "S01",
  "title": "模型为什么会变形",
  "learning_goal": "能区分网格与骨骼的作用",
  "narration": "完整口播文本",
  "screen_text": ["网格", "骨骼", "权重"],
  "visual": "骨骼转动，网格按权重变形",
  "events": [{"anchor_text": "旋转这一根骨骼", "action": "rotate_joint"}],
  "source": ["资料章节定位"],
  "checks": ["关节弯曲方向与口播一致"]
}
```

生成配音后补真实音频时长、起始时间、整段帧数与事件时标。批准脚本是内容事实源，字幕与画面数据从它生成。

## 页面设计

屏幕文字承担定位、命名与比较作用：自然标题、术语、必要参数、代码及简短结论。不要把整段讲稿搬上屏。

内部段号、制作状态、工具链名称、分镜类型标签、预估讲解时长与营销文案不进画面。未要求时不加“知识卡片”等模板角标。示意画面可能被误认为实录时，以简短自然的语言准确说明，不能制造误解。

字幕留独立安全区。标题、三维主体、注释和字幕有明确层级；DOM 变换、相机视野与最终字幕层一起检查。1080p 可从标题 52–72 px、标签 28–40 px、字幕 36–44 px 起步，再根据实际编码抽帧调整。字号仅是起点。

## 教学镜头检查点

- 模型：选择与拓扑变化实际可见，顶点、边、面准确对应。
- UV：同一网格展开与纹理对应，展开图不遮挡字幕。
- 材质：每次只改变讲授中的变量。粗糙度比较固定颜色、金属度、灯光、相机；金属度比较固定其他变量。金属需要可读的环境反射。
- 动画：插值有轨迹或时间轴；步行检查穿地、滑步、脚底接触与重心变化。
- 软件操作：实际应用或实验结果支持真实行为主张，概念动画保持语义准确。

画面动作绑定口播事件，不按段落百分比随意切参数。讲 A 时不能已切到 B。不同主题重新选择视觉资产，不把一集机器人或配色变成永久模板。
